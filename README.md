The official landing page for **AI Productivity Flow** — Voice, Audio, and Video intelligence for your desktop.

- **Live Website**: [https://ai-productivity-flow.vercel.app](https://ai-productivity-flow.vercel.app)

## Features
- **Hero Showcase**: Scroll-driven desktop studio showcase.
- **Problem & Solution Breakdown**: Interactive step-by-step pain point and solution narrative.
- **Interactive Desktop Demo**: Real-time dictation, multi-depth audio player, and script generation.
- **Providers & Models**: Comprehensive model ecosystem across Speech-to-Text, Text-to-Speech, and LLMs/Video.
- **Privacy First**: Local-first architecture and transparent zero-telemetry disclosure.
- **Direct Downloads**: 1-click downloads for Windows (.exe) and macOS (.dmg).
- **Vercel Analytics & Speed Insights**: Integrated visitor and Core Web Vitals tracking.
